# TaskHunt — Фриланс-Платформа нового поколения с Крипто-Эскроу

**TaskHunt** — современная децентрализованная фриланс-биржа с встроенным крипто-эскроу на базе NOWPayments, автоматизированным леджером двойной записи (Double-Entry Ledger), тарифной монетизацией и асинхронной защитой от фрода.

🌐 **Живой прод**: [taskhunt.lol](https://taskhunt.lol) — задеплоено на Azure VM, nginx + Docker Compose, SSL от Let's Encrypt. Текущий статус готовности (что реально настроено, что осознанно пусто) — [docs/PRODUCTION_READINESS.md](docs/PRODUCTION_READINESS.md).

---

## 🚀 Основные Возможности Платформы

* **💰 Двустороннее Крипто-Эскроу (Ledger & Escrow)**:
  * Депозиты и вывод в криптовалюте (NOWPayments).
  * Гарантия безопасности: деньги замораживаются на платформе при старте этапа/заказа и автоматически перечисляются фрилансеру после приемки работы.
  * Автоматический воркер выплат `WithdrawalPayoutProcessor` с транзакционным откатом (`REFUND`) при сбоях.
  * Выставление и оплата инвойсов прямо в чате заказа с возможностью экспорта счетов в CSV.
* **🛡️ Безопасность и Анти-Фрод**:
  * Двухфакторная аутентификация (2FA / TOTP) с поддержкой резервных кодов.
  * Асинхронный воркер `fraud-service`, скорящий риски (0-100 score) на основе доменных событий.
  * Автоматическое антивирусное сканирование всех загружаемых файлов в S3 через `ClamAV` daemon.
  * Ограничение частоты запросов (Rate Limiting) на чувствительных роутах.
* **💎 Гибкая Монетизация & Бустинг**:
  * Тарифные подписки (`Starter`, `Pro`, `Premium`) со сниженными комиссиями и расширенными лимитами.
  * Продвижение (буст) заказов и профилей фрилансеров в поиске и каталоге.
  * Реферальная программа с генерацией промокодов и автоматическим начислением бонусов.
* **⚡ Умный Поиск и Повторяющиеся Заказы**:
  * Умный подбор фрилансеров под навыки заказа (`Matching Engine`).
  * Полнотекстовый поиск по заказам и фрилансерам, логирование поисковых трендов.
  * Автоматическое создание регулярных заказов по расписанию (`OrderTemplateProcessor`).

## 🛠️ Архитектура Проекта

Платформа спроектирована по принципу **модульного монолита** для финансовых и доменных процессов (`apps/api`), **Next.js 14 Web App** (`apps/web`) и **событийно-управляемых фоновых микросервисов**:

```
taskhunt/
├── apps/
│   ├── api/                     # NestJS монолит — 19 доменных модулей, Ledger, BullMQ
│   ├── web/                     # Next.js 14 (App Router) — клиент + админка
│   ├── notifications-service/   # Воркер рассылок (Email, Telegram Bot, Push)
│   └── fraud-service/           # Воркер риск-скоринга и антифрод флагов
├── packages/
│   ├── shared-types/            # Общие TS-типы, DTO, схемы событий, ивенты
│   └── config/                  # Базовые конфиги TypeScript / ESLint
├── docs/                        # Полная техническая документация
│   ├── ARCHITECTURE.md          # Архитектура системы, модули, RBAC, деплой
│   ├── API_MAP.md               # Полная карта всех REST API эндпоинтов
│   ├── DEPLOYMENT.md            # Пошаговый runbook деплоя на VPS (DNS, nginx, SSL, .env)
│   ├── PRODUCTION_READINESS.md  # Реальный статус прод-деплоя — что работает, что пусто
│   └── CONTRIBUTING.md          # Руководство по локальной разработке
```

## 💻 Быстрый Старт (Локальная Разработка)

### Требования:
* Node.js v20+
* pnpm v9+ (`corepack enable`)
* Docker & Docker Compose

### 1. Запуск инфраструктуры:
```bash
# Клонировать репозиторий и установить зависимости
pnpm install

# Запустить PostgreSQL и Redis
docker compose up postgres redis -d
```

### 2. Настройка базы данных:
```bash
# Скопировать конфигурацию окружения
cp apps/api/.env.example apps/api/.env

# Применить миграции базы данных
pnpm --filter @taskhunt/api prisma:migrate

# Запустить начальный сид (обязательно для финансового контура)
pnpm --filter @taskhunt/api prisma:seed
```

### 3. Запуск сервера разработки:
```bash
pnpm dev
```
Команда запускает сервер **API** (`http://localhost:3001`) и **Web Frontend** (`http://localhost:3000`) параллельно.
